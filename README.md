# 農家ポップ

農家さんが、直売所の印刷物・SNS投稿素材・おたより・ブランドラベルを迷わず作れる、用途特化型のデザインWebアプリです。

## 実装済み

- 4つの入口: 売り場 / SNS / おたより / ブランド
- 主要テンプレート: 直売所POP、価格カード、食べ方カード、今日出せる野菜リスト、Instagram投稿、ストーリー、月のおたより
- 第二段階の下地: 農家紹介カード、メッセージカード、ロゴシール
- 野菜名、価格、農園名、説明、食べ方、品目リストの編集
- 野菜写真アップロード、左右・上下位置の簡易トリミング、プレビュー反映
- 用途、テンプレート、差し色の切り替え
- レスポンシブな制作画面
- PNG書き出し

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

本番ビルド:

```bash
npm run build
npm start
```

## 設計方針

多機能な汎用デザインツールではなく、「使う場面を選ぶ」「内容を入れる」「保存する」の短い導線を優先しています。外部画像素材がなくても、生成りの紙・深緑・手書き風・控えめな草花装飾で農園らしい温度が出るようにしています。
